┌─────────────────────────────────────────────────────────────────────────┐
│                    DEVELOPMENT WORKFLOW                                  │
└─────────────────────────────────────────────────────────────────────────┘

Step 1: Get Dataset
    ↓
    data/[disease]_data.csv

Step 2: Create Training Script
    ↓
    train_models/train_[disease].py
    (Copy from train_diabetes.py)

Step 3: Train Model
    ↓
    python train_models/train_[disease].py
    ↓
    Creates: models/[disease]/model.pkl
             models/[disease]/scaler.pkl

Step 4: Update App Config
    ↓
    Add to DISEASES dict in app.py:
    '[disease]': {
        'name': 'Disease Name',
        'model_path': 'models/[disease]/model.pkl',
        'scaler_path': 'models/[disease]/scaler.pkl',
        'features': [...]
    }

Step 5: Create Template
    ↓
    templates/diseases/[disease].html
    (Copy from diabetes.html)

Step 6: Update Landing Page
    ↓
    Change "Coming Soon" to active card
    in templates/index.html

Step 7: Test
    ↓
    python app.py
    Visit: http://localhost:5000/disease/[disease]


┌─────────────────────────────────────────────────────────────────────────┐
│                         QUICK COMMANDS                                   │
└─────────────────────────────────────────────────────────────────────────┘

Install Dependencies:
    pip install -r requirements.txt

Train Diabetes Model:
    python train_models/train_diabetes.py

Run Application:
    python app.py

Visit Application:
    http://localhost:5000

Test API:
    curl -X POST http://localhost:5000/predict/diabetes \
         -H "Content-Type: application/json" \
         -d '{"HighBP": 1, "BMI": 28.5, ...}'
