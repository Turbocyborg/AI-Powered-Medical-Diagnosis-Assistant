
DIABETES PREDICTION SYSTEM - QUICK START GUIDE
==============================================

🚀 SETUP (5 minutes):
1. pip install -r requirements.txt
2. Download BRFSS dataset from Kaggle
3. python train_model.py
4. python app.py
5. Visit http://localhost:5000

🎯 USAGE:
- Fill out the web form with health data
- Click "Predict Diabetes Risk" 
- Get instant risk assessment + recommendations

🔧 CUSTOMIZATION:
- Modify models in train_model.py
- Update UI in templates/index.html
- Add features by updating both files

📊 EXPECTED PERFORMANCE:
- Accuracy: 85-90%
- AUC Score: 0.87-0.92
- Training time: 2-5 minutes
- Prediction time: <1 second

🚨 IMPORTANT NOTES:
- For educational purposes only
- Not a replacement for medical diagnosis
- Always consult healthcare professionals
- Ensure data privacy in production
